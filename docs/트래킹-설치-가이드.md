# 트래킹 코드 설치 가이드 (스텝바이스텝)

> 코드는 이미 다 준비되어 있음. 아래는 **계정 권한이 필요해서 백관장님만 할 수 있는 것**들.
> 소요시간: 1번+2번 합쳐서 약 15분.

---

## 현재 이미 설치된 것 (아무것도 안 해도 됨)

- ✅ **Vercel Analytics** — 방문자 수·페이지별 조회수. 보는 곳: https://vercel.com 로그인 → baekwebpage 프로젝트 → Analytics 탭
- ✅ OG 태그 (카톡/페북 공유 시 이미지+제목 표시)
- ✅ 페이지별 제목, canonical, sitemap.xml, robots.txt
- ✅ JSON-LD 구조화 데이터 (구글·AI 검색이 사이트를 이해하는 데 사용)

---

## 1. 구글 서치콘솔 (필수 · 5분) — 구글 검색에 노출되기

1. https://search.google.com/search-console 접속 → 구글 계정 로그인
2. "속성 추가" → 오른쪽 **"URL 접두어"** 선택 → `https://masterbaek.vercel.app` 입력 → 계속
3. 확인 방법 중 **"HTML 태그"** 선택 → 이런 코드가 보임:
   ```html
   <meta name="google-site-verification" content="AbCdEf123..." />
   ```
   여기서 **content 안의 값만** 복사 (따옴표 안 문자열, `AbCdEf123...` 부분)
4. **서치콘솔 창은 닫지 말고** 새 탭에서 https://vercel.com → baekwebpage 프로젝트 → **Settings → Environment Variables**
5. 다음과 같이 추가 → Save:
   - Key: `GOOGLE_SITE_VERIFICATION`
   - Value: (3에서 복사한 값)
   - Environment: Production 체크
6. 재배포: 프로젝트 → **Deployments 탭 → 맨 위 배포 오른쪽 ⋯ 메뉴 → Redeploy** (환경변수는 재배포해야 반영됨)
7. 배포 완료(1~2분) 후 서치콘솔 탭으로 돌아가 **"확인"** 버튼 클릭 → "소유권이 확인됨" 뜨면 성공
8. 마지막으로 서치콘솔 왼쪽 메뉴 **"Sitemaps"** → `sitemap.xml` 입력 → 제출

## 2. 네이버 서치어드바이저 (필수 · 5분) — 네이버 검색에 노출되기

1. https://searchadvisor.naver.com 접속 → 네이버 로그인 → 우측 상단 "웹마스터 도구"
2. 사이트 등록: `https://masterbaek.vercel.app` 입력
3. 확인 방법 중 **"HTML 태그"** 선택 → content 값만 복사 (1번의 3단계와 동일한 요령)
4. Vercel 환경변수 추가 (1번의 4~5단계와 동일):
   - Key: `NAVER_SITE_VERIFICATION`
   - Value: (복사한 값)
   - Environment: Production 체크
5. Redeploy (1번의 6단계와 동일) → 서치어드바이저에서 **"소유확인"** 클릭
6. 확인되면 왼쪽 메뉴 **요청 → 사이트맵 제출** → `https://masterbaek.vercel.app/sitemap.xml` 제출

> 💡 1번을 먼저 끝냈으면 2번은 같은 재배포에 묶어도 됨: 환경변수 2개를 다 넣고 Redeploy 한 번만.

## 3. GA4 (선택 — 지금은 불필요)

Vercel Analytics가 방문자·페이지뷰를 이미 잡고 있어서 당장 필요 없음.
나중에 **광고 집행하거나 전환 퍼널(칼럼→상품 클릭률)을 정밀 분석**하고 싶어지면:
analytics.google.com에서 속성 만들고 **측정 ID(G-XXXXXXX)만 클로드에게 주면 코드 한 줄로 설치** 가능.

## 4. 메타 픽셀 (선택 — 광고 돌릴 때만)

인스타/페북 유료 광고를 시작할 때만 필요. 그 전엔 설치해봤자 쓸 데이터가 없음.
시작하게 되면 Meta 비즈니스 관리자에서 픽셀 ID 받아서 클로드에게 주면 됨.
