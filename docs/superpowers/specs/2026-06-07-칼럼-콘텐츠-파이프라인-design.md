# 칼럼 콘텐츠 파이프라인 설계 (P2 재설계)

> 작성일: 2026-06-07
> 관련: [CLAUDE.md](../../../CLAUDE.md) · [구현계획.md](../../../구현계획.md)

## 배경 / 문제

기존 P2 구상은 "노션에 쓴 글을 그대로 사이트에 노출"하는 것이었다.
그러나 실제 노션 콘텐츠를 점검한 결과, **사이트에 바로 쓸 수 있는 글이 없다.**

- **`발행 완료 > 유튜브`**: 100편 이상의 raw 대본·쇼츠 메모. 제목부터 "쇼츠, AGT",
  "뷰O/뷰X" 같은 작업 메모투성이. 사람에게 보여줄 글이 아니라 영상 대본용.
- **`자동화 > 뉴스레터 출력`**: 글은 다듬어졌으나 `ver.2`, `ver.3`, `확장본` 등
  여러 버전이 섞여 있고 **이미지가 없다.** 발송용이지 사이트 게시용이 아니다.

→ 결론: **모든 콘텐츠는 사이트 칼럼용으로 재가공이 필요하다.**
"노션 원문 그대로 노출"은 폐기하고, **가공 단계를 끼워넣는 구조**로 재설계한다.

## 확정된 결정 (브레인스토밍 결과)

1. **가공 주체**: AI가 1차 가공 → 백관장이 감수. (기존 marketingteamforbaek 자산 활용 가능)
2. **표지 이미지**: 칼럼별 그림을 만들지 않는다. **제목 + 남색 배경 텍스트 카드**를
   사이트가 자동 생성. (IBM Carbon "신뢰감·군더더기 없음" 컨셉과 일치, 비용 0, 운영 가벼움)
3. **저장 위치**: 노션에 **사이트 전용 "홈페이지 칼럼" DB를 신설**. 기존 원본은 보존하고
   사이트에 낼 깨끗한 글만 새 DB에 담는다. 사이트는 이 DB만 읽는다.

## 콘텐츠 흐름

```
[원본] 노션 발행완료/뉴스레터 (지저분한 대본·메모, 손대지 않음 = 보존)
   │
   │ ① AI 1차 가공 (Claude / marketingteamforbaek)
   │    - 사이트 칼럼 형식으로 재구성 (제목·요약·본문·소제목)
   ▼
[신규] 노션 "홈페이지 칼럼" DB  ← 여기에 '초안'으로 들어감
   │ ② 백관장 감수·수정 (노션에서)
   │ ③ 윤문 (/humanize-korean)
   │ ④ 상태 → '발행완료'
   ▼
[사이트] 발행완료만 자동으로 읽어옴 (ISR) → 칼럼으로 노출
```

핵심 안전장치: **상태가 `발행완료`가 아닌 글은 사이트에 절대 노출되지 않는다** (감수 게이트).

## 노션 신규 DB 스키마 — "홈페이지 칼럼"

| 속성 | 타입 | 용도 |
|------|------|------|
| 제목 | title | 칼럼 제목 |
| 요약 | text | 목록 카드·OG 설명 (1~2줄) |
| slug | text | 주소 (`/columns/<slug>`) |
| 상태 | select | `초안` / `감수중` / `발행완료` — **발행완료만 노출** |
| 등급 | select | `A`=홈 추천칼럼 / `B`=일반 |
| 날짜 | date | 정렬 기준 |
| (본문) | 페이지 내용 | 실제 글 (노션 블록) |

## 사이트 연동

- `/columns` (목록) + `/columns/[slug]` (상세) — 현재 더미를 **노션 DB 연동으로 교체**
- 노션 SDK로 `상태=발행완료`만 쿼리. `등급=A`는 홈 추천 영역에 노출
- **ISR**: 일정 주기 자동 재검증(초기값 예: 60초~1시간, 조정 가능) → 재배포 없이 반영
- 본문 렌더링: 노션 블록 → HTML (제목·문단·목록·굵게·인용 등 기본 블록)
- slug 미입력 시 폴백 규칙 필요 (예: 페이지 id 기반). 가공 단계에서 slug를 채우는 것을 원칙으로 함.

## 표지 (이미지 없이)

- 칼럼마다 그림 없음 → **제목 + 남색(#004AAD) 배경 텍스트 카드**를 사이트가 자동 렌더
- 적용 위치: 목록 카드 / 상세 상단 / OG 이미지 — 모두 동일 방식으로 통일
- 후속 옵션: 특정 칼럼만 직접 사진을 얹고 싶으면 추후 표지 이미지 속성 추가 가능 (YAGNI — 지금은 안 함)

## 사전 준비 (사용자 1회, 코드로 불가)

- 노션 Integration 토큰 발급 → 새 "홈페이지 칼럼" DB에 연결 → Vercel 환경변수 저장
- 새 DB 생성은 Claude가 노션 MCP로 대행 가능. 토큰 발급·연결·환경변수 저장은 사용자 협조 필요.
- 필요한 환경변수(예): `NOTION_TOKEN`, `NOTION_COLUMNS_DB_ID`

## 구현 순서

1. 노션 "홈페이지 칼럼" DB 생성 + 토큰 연결 (사용자 협조 구간)
2. **샘플 1편** AI 가공 → DB에 넣어 결과물 확인 (눈으로 품질 체크 후 진행 결정)
3. 사이트 칼럼 목록/상세를 노션 연동으로 교체 + 표지 자동생성
4. ISR·홈 추천(등급 A) 연결
5. 검증 후 나머지 칼럼 순차 가공·발행

## 범위 밖 (이번에 하지 않음)

- 칼럼별 개별 이미지/AI 이미지 생성
- 상품 상세(P3)·소개/문의(P4)·자가진단(P6)
- 이메일 수집/자동화
- 도메인 연결

## 성공 기준

- 노션 "홈페이지 칼럼" DB에서 `발행완료`로 표시한 글이 사이트 `/columns`에 자동 노출된다.
- 초안·감수중 글은 사이트에 절대 보이지 않는다.
- 칼럼 표지가 그림 없이 남색 텍스트 카드로 통일되어 렌더된다.
- 노션에서 글을 발행완료로 바꾸면 재배포 없이 ISR 주기 내에 사이트에 반영된다.
- 등급 A 칼럼이 홈 추천 영역에 노출된다.
