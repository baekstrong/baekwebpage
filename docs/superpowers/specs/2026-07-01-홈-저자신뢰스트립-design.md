# 홈 저자·신뢰 스트립 — design

날짜: 2026-07-01
상태: 설계 승인됨 (구현 대기)

## 목표
홈 첫 화면에 백관장의 공신력을 **자연스럽게** 얹어 신뢰·전환을 높인다. 3종 신호:
1. 《최소한의 생존 체력 운동》 **저자** (정식 출간 저서)
2. 체력 운동 전문 **근력학교 이사**
3. 유튜브 6.2만 (이미 히어로/스탯에 있음 — 스트립에서 한 번 더 자연스럽게 묶음)

과하지 않게 = **신뢰 스트립 1개** + 스토리 서명에 직함 한 줄. 이게 전부(스코프 고정).

## 배치
`app/page.tsx` 의 **오리진 스토리(`.sg-story`, ~131–151행) 바로 뒤, 칼럼 섹션(`.sg-sect#columns`, 154행) 앞**에 스트립 삽입.
근거: 스토리로 사람을 소개한 직후 공신력을 못 박는 흐름이 가장 자연스럽고 안 뜬다.

## 레이아웃 (에디토리얼 Structured Grid 톤)
```
─────────────────────────────────────────────  (상단 1.5px #15171C)
 ┌──────┐   ▍저서 · 백관장은
 │ 표지 │   《최소한의 생존 체력 운동》  — 정식 출간 저서
 │ 이미지│   직장인 체력 전문 코치 · 근력학교 이사 · 유튜브 6.2만 구독
 └──────┘   저서 보러가기 →
─────────────────────────────────────────────  (하단 1px #E4E9F0)
```
- 좌: 표지 세로 썸네일 폭 ~112px. 얇은 hairline 보더(그림자 최소).
- 우:
  - 모노 라벨 `▍저서 · 백관장은` (파랑 `--sg-blue`)
  - 제목 줄: **《최소한의 생존 체력 운동》** (20px/800) + ` — 정식 출간 저서`(회색)
  - 크레덴셜 줄(모노, 회색): `직장인 체력 전문 코치 · 근력학교 이사 · 유튜브 6.2만 구독`
  - `저서 보러가기 →` 표시(`<span className="read">`)
- 스트립 전체가 `/products/book-survival`로 가는 **하나의 `<Link>`**(카드형) — hover시 배경 `--sg-surf2`. `저서 보러가기 →`는 시각 표시용 span이며 **중첩 앵커를 만들지 않는다**(strip 자체가 앵커).

## 서명 보강 (스트립 외 유일한 추가 터치)
`.sg-sign` 의 `— 백관장 (백승덕)` → `— 백관장 (백승덕) · 근력학교 이사`.

## 이미지
표지 파일을 `public/book-cover.jpg` 로 저장(사용자가 첨부 이미지를 해당 경로에 배치). 코드에서 `/book-cover.jpg` 참조, `alt="《최소한의 생존 체력 운동》 표지"`. 파일 부재 시에도 레이아웃은 깨지지 않게(빈 이미지 박스) 처리.

## 손대는 파일
- `app/page.tsx` — 스트립 삽입(스토리 뒤) + 서명 직함 추가.
- `app/globals.css` — `.sg-author*` 추가.
- `public/book-cover.jpg` — 표지 이미지(사용자 배치).

## 범위 밖 (YAGNI)
- 히어로/캡션/eyebrow 변경 없음.
- 스탯 스트립 변경 없음.
- 다른 페이지(about 등)엔 손대지 않음.
- 별도 저자 전용 섹션·다중 크레덴셜 블록 없음.

## 검증
- `tsc --noEmit` 통과 · CSS 중괄호 균형.
- 로컬 빌드 불가(iCloud) → Vercel 게이트.
- 라이브에서 스토리→스트립→칼럼 순서·표지 렌더·서명 직함 육안 확인.
